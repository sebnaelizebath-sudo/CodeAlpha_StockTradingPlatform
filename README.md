# CodeAlpha Stock Trading Platform

## About the Project

Stock Trading Platform is a Java-based application developed as part of the CodeAlpha Java Programming Internship.

The application allows users to view stock information, buy and sell stocks, and manage their portfolio.

## Features

- View stock information
- Buy stocks
- Sell stocks
- Manage portfolio
- Display portfolio details
- Track trading activities

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Console-based Application

## How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA or any Java IDE.
3. Open the main Java file.
4. Compile and run the program.
5. Enter the required details when prompted.
